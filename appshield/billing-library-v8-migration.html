Google Play Billing Library v8: minimum version and migration

Google requires Play Billing Library version 8 or higher for new apps and app updates that use Google Play's billing system, starting August 31, 2026, with extensions available to November 1, 2026 through Play Console. As of this writing, v9.x is the current release line.

Set the gradle dependency

In your app module's build.gradle, set the Billing Library dependency to v8 or higher:

dependencies {
    implementation("com.android.billingclient:billing-ktx:8.0.0")
}

Use billing-ktx if your code calls the Kotlin extension APIs, or com.android.billingclient:billing for the plain Java API surface. Either artifact satisfies the v8+ requirement at the same version number. Since v9.x is current, a new integration can pin the latest 9.x release directly rather than starting at 8.0.0.

What actually changes in the migration

Bumping the dependency number alone will not compile if your integration predates v8; the main work is in two places:

  • BillingClient callback shape. Several listener interfaces and callback signatures were revised across the v6/v7 to v8 transition. Code written against the older callback interfaces needs to be updated to the current interfaces before it will build.
  • ProductDetails API changes. The APIs for querying product details and building purchase flow params have changed shape across these versions. Any code constructing QueryProductDetailsParams, reading pricing off ProductDetails, or building BillingFlowParams needs to be checked against the current API surface, not the older SkuDetails-based APIs that v8 no longer supports.

Because the exact method signatures differ by the specific version you are migrating from, follow Google's official migration guide step by step rather than guessing at the diff.
