Expo: target API 36

Google requires most apps and updates to target API level 36 (Android 16) starting August 31, 2026, with extensions available to November 1, 2026 through Play Console. Expo apps have two ways to hit this: upgrade the Expo SDK, or set the value explicitly.

Upgrade the Expo SDK Set it explicitly EAS build note Official sources

Option 1: upgrade to an Expo SDK release that targets API 36

Each Expo SDK release ships with a default Android targetSdkVersion baked into its prebuild templates and native modules. The straightforward fix is upgrading to whichever current Expo SDK release targets API 36 by default:

npx expo install expo@latest
npx expo-doctor

Run npx expo-doctor after upgrading to catch dependency version mismatches, then rebuild native code with npx expo prebuild --clean if your project has an android/ directory checked in.

Option 2: set android.targetSdkVersion via expo-build-properties

If you are not ready to upgrade the full SDK, override the target SDK directly in app.json using the expo-build-properties config plugin:

npx expo install expo-build-properties
{
  "expo": {
    "plugins": [
      [
        "expo-build-properties",
        {
          "android": {
            "targetSdkVersion": 36,
            "compileSdkVersion": 36
          }
        }
      ]
    ]
  }
}

This plugin patches the generated gradle files at prebuild time, so it works whether or not you keep a native android/ folder checked into version control.

EAS build note

If you build with EAS (eas build), the target SDK is still determined by your app.json config plugin settings or Expo SDK version, EAS just runs the prebuild and native build remotely. After changing either the SDK version or the expo-build-properties config, trigger a fresh EAS build (a cached build will still reflect the old configuration) and confirm the resulting .aab targets API 36 before submitting to Play Console.
