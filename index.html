APPSHIELD / FINDING 01

Screenshot mismatch

Fix before submission

What we observed

Listing image 02 depicts “Explore trails.” In the fictional build 1.8 (42), the same entry opens Sunset Loop with no discovery control.

E-01 · listing-image-02.pngE-02 · build-1.8-42 / Trails

Why it matters

A reviewer can reach the saved route, but cannot reproduce the discovery experience your listing advertises.

Recommended correction

  1. Capture the current Trails screen from the exact build you intend to submit.
  2. Replace image 02 and rewrite its caption around the saved-route experience.
  3. Compare every remaining image and caption with that same build.

Acceptance checks

  • The replacement image matches the current interface.
  • The pictured flow is reachable using reviewer access.
  • The caption makes no claim the supplied screen cannot support.
The useful change

An unsupported feature promise becomes an accurate, reproducible listing.

The correction shown here updates the listing. It does not add a discovery feature or predict store approval.
