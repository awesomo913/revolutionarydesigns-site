# Gritty Mix game previews

`gritty-nursery-preview.webp` and `gritty-bench-preview.webp` are captures of Revolutionary Designs’ Gritty Mix browser game, prepared September 8, 2026. The nursery preview shows a staged collection with nonessential game statistics hidden. The bench preview shows the game’s grafting canvas.

These are illustrated game previews, not botanical reference photographs. Underlying sprite artwork and real-plant reference attribution are documented in [Gritty Mix sprite credits](../../gritty-mix/assets/SPRITE-CREDITS.md); the same stated license applies to the derivative artwork here.
